Questions, answered

The practical stuff.

Do guests need the repository?+

No. Only the host needs the repository, Git, and the selected coding-agent CLI. Guests can join the shared session without cloning the project.

Does MultiCode share or edit guest workspaces?+

No. MultiCode shares the agent conversation and review flow. Participant folders and files stay local and are never synchronized with the host.

Which coding agents are supported?+

Codex is supported, and Claude is available as an experimental external-CLI integration using the host’s subscription login or API key.

Can the relay see our prompts or code?+

The public relay routes encrypted application payloads. It can see routing metadata and payload sizes, but not prompts, agent output, previews, or proposals.

What happens to agent changes?+

The agent works in a temporary isolated worktree. Accepted results are applied to the host checkout as ordinary changes, while guests receive read-only previews.
