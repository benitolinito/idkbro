# MultiCode support

## Getting help

Before reporting a problem, run **MultiCode: Check Setup** from the VS Code Command Palette and review the **MultiCode** output channel.

Search existing issues or open a new one at:

https://github.com/benitolinito/idkbro/issues

Include:

- Your operating system and VS Code version
- The MultiCode extension version
- Whether you were hosting or joining
- Whether the selected agent was Codex or Claude
- Relevant sanitized output from the **MultiCode** output channel
- Steps that reproduce the problem

Never post room invitation tokens, API keys, access tokens, authentication files, or private repository contents in a public issue.

## Security vulnerabilities

Please report suspected vulnerabilities privately through GitHub Security Advisories:

https://github.com/benitolinito/idkbro/security/advisories/new

Do not disclose an unpatched vulnerability in a public issue.
