# Changelog

All notable changes to the MultiCode VS Code extension are documented here.

## 0.4.11

- Improved Marketplace title, description, categories, tags, resources, and visual presentation.
- Added concise installation and three-step collaboration guidance to the Marketplace listing.
- Copied invitations now include the Marketplace installation link and join instructions.
- Added Marketplace version and installation badges.
- Added dedicated support and release-history documents.

## 0.4.10

- Added the interactive Ink terminal interface with Codex, Claude, and join launch options.
- Packaged the Ink-enabled CLI as a self-contained ESM artifact in the VS Code extension.
- Added masked invitation input, live session status, transcript output, and terminal interaction tests.
